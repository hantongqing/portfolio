# 作品集

AI 产品经理个人作品集，以深蓝科技风页面集中展示 GitHub 公开项目。

🔗 **在线访问**：[https://hantongqing.github.io/portfolio/](https://hantongqing.github.io/portfolio/)

---

## 📌 项目简介

面向求职和项目分享场景的纯前端网站。首页保留“我的项目”标题和“AI Agent 产品设计 · 多智能体系统 · 智能体工程实践”副标题，下方直接展示 `hantongqing` 的 GitHub 公开仓库。

项目名称、描述、主要编程语言、星标数和创建日期均来自 GitHub API，点击“查看”可进入对应仓库。维护 GitHub 仓库信息后，重新加载页面即可获取最新内容。

---

## ✨ 核心功能

- **公开项目展示**：按创建时间倒序排列，每页最多获取并展示 50 个公开仓库。
- **分页浏览**：使用“上一页 / 下一页”浏览更多项目，突破单次请求的数量限制；已访问的页面在本次浏览中缓存。
- **仓库信息卡片**：展示项目名称、描述、语言、星标数、创建日期和仓库链接。
- **深蓝科技风界面**：流动渐变背景、星光、蓝色光粒和磨砂玻璃卡片。
- **响应式布局**：桌面端每行五个项目，每页最多十行；平板端三列、手机端单列。
- **日夜模式切换**：支持主题切换，并在浏览器中保存选择。
- **返回顶部**：滚动后显示返回顶部按钮。
- **加载状态提示**：显示当前页码和项目数量，提供加载中、末页、空列表和失败重试提示；翻页失败时保留当前项目。

##  本地运行

双击 `index.html`，用浏览器打开即可，无需安装依赖。加载公开仓库列表需要联网；页面通过公开 API 获取数据，不需要填写 GitHub Token 或 API Key。

如果 GitHub 请求失败，请稍后刷新。未认证的 GitHub API 请求存在速率限制。

## 部署与维护

网站通过 GitHub Pages 发布。修改页面后，将代码推送到仓库，并等待 Pages 部署完成。

项目展示内容直接来自 GitHub 仓库信息，无需在网页中手动维护项目介绍。若要展示其他账号的仓库，可修改 `index.html` 中的 `GITHUB_USER`。
