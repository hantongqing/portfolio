# 作品集

AI 产品经理作品集 - 深蓝科技风个人网站，自动同步 GitHub 项目。

🔗 **在线访问**：https://hantongqing.github.io/portfolio/

---

## 📌 项目简介

面向求职场景的个人作品集网站，展示 AI Agent 产品设计能力与项目经验。深蓝科技风格，纯前端实现，支持 GitHub 项目自动拉取。

---

## ✨ 核心功能

- **精选项目展示**：AIGC 多智能体短剧生成系统、Pico 本地代码智能体 Harness
- **GitHub 自动同步**：实时拉取公开仓库，按创建时间倒序排列
- **深蓝科技风 UI**：流动天空背景、蓝色光粒、磨砂玻璃卡片、滚动淡入动画
- **响应式设计**：适配桌面端与移动端
- **日夜模式切换**：一键切换白天/夜晚主题

---

##  技术栈

| 技术 | 说明 |
|------|------|
| HTML5 | 语义化结构 |
| CSS3 | 渐变、动画、磨砂玻璃效果 |
| JavaScript (Vanilla) | GitHub API 调用、交互逻辑 |
| GitHub Pages | 静态网站托管 |
| GitHub API v3 | 自动拉取公开仓库 |
